# النصر — نظام إدارة مكتب المحاماة

مشروع إدارة مكتب محاماة متخصص في قضايا الديون والائتمان في دولة الإمارات العربية المتحدة.

> هذا المشروع لا يقدم استشارة قانونية؛ المحتوى الحقوقي والإجرائي يجب مراجعتها واعتمادها من محامٍ مرخص في الإمارات وتحديثه باستمرار حسب الجهات الرسمية.

## النطاق الحالي

- لوحة قيادة إدارية
- إدارة العملاء والقضايا
- مسار حياة الملف
- بيانات البنوك وملفاتها
- نماذج البريد المعتمدة للمراجعة
- المحاسبة وحاسبة صافي الحقيقة
- صلاحيات الموظفين
- نظام النقاط والتقييم

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`.
